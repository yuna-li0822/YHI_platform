# Young Heart Innovators - Heart Valve Device Explorer

A modern educational web app built with React, TypeScript, React Three Fiber, Drei, Framer Motion, TailwindCSS, and React Icons.

## Features

- Interactive 3D heart valve device viewer
- Device library with search and sidebar navigation
- Dynamic information panel with clinical and engineering details
- Hotspots on 3D models for component-level explanations
- Learning cards, comparison mode, and interactive quiz
- Modern glassmorphism UI with health-tech styling

## Setup

1. Install Node.js (LTS recommended).
2. In the project folder, run:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the app in your browser at the local address shown by Vite.

## Available Scripts

- `npm run dev` - Start the local development server
- `npm run build` - Build the production app
- `npm run preview` - Preview the production build locally

## Notes

This project is ready for deployment once dependencies are installed. The app uses placeholder 3D forms for device models and can be extended with real GLTF assets or clinical imagery.

## Viewing users / metrics

To view real user analytics and metrics, connect the deployed site to an analytics platform such as Google Analytics, Plausible, or Vercel Analytics after deployment.
